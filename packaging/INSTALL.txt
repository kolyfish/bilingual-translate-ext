雙語對照翻譯（Chrome 擴充功能）安裝說明
==========================================

這是什麼
--------
- 網頁：按 Option+A（Windows 是 Alt+A），英文段落下方會出現中文翻譯
- YouTube：開英文字幕後，畫面上會出現「英文＋中文」雙語字幕
- 預設用 Chrome 內建的本機翻譯，文字不會送出你的電腦，也不用付費


Mac 安裝
--------
1. 先把這個 zip 解壓縮（在 zip 上點兩下）
2. 在「Install-Mac.command」上按右鍵 → 「打開」 → 再按一次「打開」
   （第一次一定要用右鍵打開，直接點兩下 Mac 會說「無法驗證開發者」而擋住）
3. 安裝程式會自動打開 Chrome 的擴充功能頁面，並把安裝路徑複製到剪貼簿
4. 在擴充功能頁面：
   a. 打開右上角的「開發人員模式」
   b. 點左上角「載入未封裝項目」
   c. 按 ⌘ + Shift + G，再按 ⌘ + V 貼上，按 Enter
   d. 按「選取」


Windows 安裝
------------
1. 先把這個 zip 解壓縮（右鍵 → 全部解壓縮）
2. 在解壓縮出來的資料夾裡，點兩下「Install-Windows.bat」
   （如果跳出「Windows 已保護您的電腦」，按「其他資訊」→「仍要執行」）
3. 安裝程式會自動打開 Chrome 的擴充功能頁面，並把安裝路徑複製到剪貼簿
4. 在擴充功能頁面：
   a. 打開右上角的「開發人員模式」
   b. 點左上角「載入未封裝項目」
   c. 點選資料夾視窗上方的路徑列，按 Ctrl + V 貼上，按 Enter
   d. 按「選擇資料夾」


裝好之後
--------
- 工具列會出現紅色「譯」字圖示；沒看到的話，點拼圖圖示把它釘選出來
- 開一篇英文網頁，按 Option+A（Windows：Alt+A）
- 第一次會在右下角出現「下載本機翻譯語言包」，按「下載並翻譯」，只需要一次
- YouTube：點「譯」圖示 → 打開「YouTube 自動雙語字幕」→ 影片開英文 CC


常見問題
--------
Q：Chrome 每次開啟都提醒「停用開發人員模式擴充功能」？
A：這是 Chrome 對不是從商店安裝的擴充都會顯示的提醒，按右上角關掉就好，不要按「停用」。

Q：網銀、Gmail、登入頁面按了沒反應，圖示出現紅色 ✕？
A：這是刻意的保護。敏感網站和有密碼欄位的頁面一律不翻譯。

Q：怎麼更新？
A：拿到新版安裝包後，再跑一次安裝程式，然後在擴充功能頁面按 ↻（重新載入）。

Q：想要更好的翻譯品質？
A：可以在「譯」圖示的設定裡改用 Claude（需要自己的 Anthropic API 金鑰，依用量付費）。
   設定裡有每日花費上限，預設 US$1。
